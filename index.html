Мой подход

Процесс: от discovery до релиза

Каждый этап заканчивается артефактом, который становится входными данными для следующего.

  1. Интервью с пользователями, анализ воронки и конкурентов. Формулирую проблему, гипотезу и целевую метрику.

    • Интервью с пользователями
    • Анализ воронки
    • Анализ конкурентов
    • Problem statement и гипотеза
    • Целевая метрика
    На выходеБриф и гипотеза
    Стек

  2. Оцениваю решения по влиянию и затратам (ICE / RICE) и фиксирую минимальный объём, достаточный для проверки гипотезы.

    • Список возможных решений
    • Оценка по ICE / RICE
    • Скоуп MVP
    • Бэклог следующих итераций
    На выходеСкоуп MVP
    Стек

  3. Проектирую user flow и карту состояний: основной путь, ошибки, пустые и граничные кейсы. До разработки проверяю прототип юзабилити-тестом.

    • User flow
    • Карта состояний
    • Ошибки, пустые и граничные кейсы
    • Кликабельный прототип
    • Юзабилити-тест
    На выходеВалидированный прототип
    Стек

  4. Токены, компоненты и их состояния, светлая и тёмная темы, доступность по WCAG 2.1 AA. Макеты собираю только из компонентов системы.

    • Дизайн-токены
    • Компоненты и их состояния
    • Светлая и тёмная темы
    • Доступность WCAG 2.1 AA
    • Макеты из компонентов системы
    На выходеКомпоненты и макеты
    Стек

  5. Собираю фронтенд с AI на компонентах дизайн-системы, делаю код-ревью и проверяю каждый экран в браузере. Закладываю разметку событий аналитики.

    • Фронтенд на компонентах системы
    • Код-ревью
    • Проверка экранов в браузере
    • Разметка событий аналитики
    На выходеРабочий билд
    Стек

  6. Релиз в продакшен. Продукт собран на тех же компонентах и токенах, что и макеты, — без расхождений между дизайном и кодом.

    На выходеРелиз
    Стек

  7. Сравниваю метрику с целевой из брифа и фиксирую решение в decision log. Выводы становятся входными данными для следующей итерации.

    • Сравнение с целевой метрикой
    • Решение в decision log
    • Входные данные следующей итерации
    На выходеНовый бриф
    Стек
