# vasnevdesign.ru

Сайт-портфолио Романа Васнёва, продуктового дизайнера.

Сейчас это мобильный прототип (ширина до 450 px) на чистом HTML/CSS/JS:
- `index.html` — главная: лоадер, падающие бейджи (Matter.js), появление блоков из блюра, меню;
- `project.html` — шаблон страницы проекта;
- `assets/` — аватар и иконки;
- `vendor/matter.min.js` — физический движок.

Деплой: Vercel, статический сайт без сборки (Framework Preset: Other).
